📷 NH-29 GPS Map Camera
Photo → GPS → KML Chainage → Village → GPS Photo
STEP 1 — PHOTO
iPhone Camera/Photos से photo चुनें। Tool photo GPS (EXIF) पहले पढ़ेगा; नहीं मिलने पर iPhone GPS मांगेगा.
Photo चुनें.
STEP 2 — KML / KMZ
Apni KML/KMZ route file ek baar select करें। Photo लेते समय current live GPS से nearest KML chainage automatically मिलेगा.
KML/KMZ select करें.
STEP 3 — AUTOMATIC DETAILS
Manual Latitude / Longitude / Chainage / Village की जरूरत नहीं.
STEP 4 — GPS PHOTO
iPhone में Save/Share दबाएँ और Share Sheet में Save Image चुनें। अगर option न दिखे तो Open Final Photo करके image को long-press → Save to Photos करें.
